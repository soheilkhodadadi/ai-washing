# Construct Playbooks

These playbooks explain how the main empirical constructs are built, validated, and safely modified. They are coauthor-facing guides, not new empirical results. Use them before changing a table script or replacing a data product.

## Playbooks

- `ai_disclosure_and_classifier_constructs.md`: sentence extraction, classifier outputs, AI Focus, actionable/speculative/irrelevant measures, and classifier-risk checks.
- `patent_mismatch_construct.md`: PatentMismatch definition, patent support, future realization outcomes, and construct-validity risks.
- `patent_matching_and_company_identity.md`: company/assignee matching, aliases, keyword evidence, and patent audit examples.
- `crsp_compustat_linkage_and_market_return_tests.md`: WRDS/Compustat/CRSP bridge, event returns, market features, and factor alpha tests.
- `capital_raising_proxy.md`: Test 30 share-growth proxy and future SEO/offering-terms extension.
- `execucomp_incentives.md`: Test 25 CEO incentive data and safe ExecuComp refresh policy.
- `sec_scrutiny_enforcement_timing.md`: comment-letter cleanup and SEC enforcement-salience timing.

For table ownership, use `docs/paper_table_workbench.md`. For private-data paths, use `docs/panel_and_data_catalog.md` and `docs/private_data_contract.md`.
