# Patent Source Inventory

Generated: 2026-06-10

## Purpose

This file is the coauthor-facing inventory for the patent source lane. It separates what is required for v4.3 reproduction support, what is useful for audit and extension, and what is optional raw-source material.

## Core Private Data Room Paths

All paths below are logical paths under `$AIW_DATA_ROOT`.

## Raw PatentsView Source Policy

The full raw PatentsView grant/pregrant source is large and is not needed for normal v4.3 table reproduction. The private data room currently stages source documentation:

```text
data/raw/patentsview/Guide/2026BulkDataProductDescriptions.xlsx
data/raw/patentsview/Guide/PV_grant_data_dictionary.pdf
data/raw/patentsview/Guide/PV_pregrant_data_dictionary.pdf
data/raw/patentsview/Guide/Bulk Data Directory _ Open Data Portal.html
data/raw/patentsview/README_PATENTSVIEW_SOURCE.md
```

The ported source resolvers expect these raw families if a coauthor wants a bottom-up rebuild:

Grant lane:

```text
g_patent.tsv
g_patent_abstract.tsv
g_assignee_disambiguated.tsv
g_application.tsv
```

Pregrant lane:

```text
pg_published_application.tsv
pg_published_application_abstract.tsv
pg_assignee_disambiguated.tsv
pg_applicant_not_disambiguated.tsv
pg_granted_pgpubs_crosswalk.tsv
```

A full raw mirror can be added under `$AIW_DATA_ROOT/raw/patentsview/granted` and `$AIW_DATA_ROOT/raw/patentsview/pregrant` if coauthors ask for bottom-up raw-source rebuilds. It should not be committed to Git.

## Repo Code Surface

The portable patent code is under:

```text
src/semantic_ai_washing/patents/
```

Important modules:

- `keyword_matching.py`: keyword loading, boundary-aware matching, and organization-name normalization.
- `build_company_lookup.py`: lookup and alias construction helpers.
- `patentsview_sources.py`: grant-side source layout resolver.
- `pregrant_sources.py`: pregrant-side source layout resolver.
- `extract_filtered_patents_lightweight.py`: grant-side count/example/diagnostic builder.
- `extract_filtered_pregrant_applications_lightweight.py`: pregrant-side count/example/diagnostic builder.
- `run_patent_fuzzy_sensitivity_sample.py`: bounded fuzzy stress-test sampler.
