# Result Notes

- Expanded annual backbone: `50,840` firm-years across `5,084` ever-speaker firms.
- Accounting coverage is the main annual-panel screen: `31,006` rows have the core annual controls, but only `17,934` retain R&D/assets.
- Market linkage is a second major screen: `23,747` annual rows have year-end CRSP market cap, and `20,391` retain next-year share growth.
- Filing-event backbone: `7,355` annual 10-K events; `4,774` survive to the 12-month BHAR window.
- Legacy determinants baseline: `5,084` 2016 firms, but only `2,652` retain the core baseline controls and `1,466` retain R&D/assets.
